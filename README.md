# Sprint_5 — Автотесты для сервиса Stellar Burgers

Проект содержит автотесты на Selenium для учебного сервиса  
https://stellarburgers.education-services.ru/

Тестируется функциональность:
- Регистрация
- Вход (4 способа)
- Переход в личный кабинет
- Переход из ЛК в конструктор
- Выход из аккаунта
- Раздел «Конструктор» (Булки / Соусы / Начинки)

---

##  Стек технологий

- Python 3.14
- Selenium
- Pytest
- Google Chrome
